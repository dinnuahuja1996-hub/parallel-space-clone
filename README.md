# Parallel Space Clone

Android app that lets you run multiple accounts of the same app using NewBlackbox virtual engine.

## Features
- Clone any installed app
- Run multiple accounts simultaneously
- Lightweight and fast

## Build

GitHub Actions automatically builds APK on every push.

Download latest APK from [Releases](../../releases).

## Setup

1. Fork this repo
2. Push any change to `main` branch
3. GitHub Actions will build APK automatically
4. Download APK from Actions > Artifacts or Releases
